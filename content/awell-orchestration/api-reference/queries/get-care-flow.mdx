---
title: Get care flow
description: Get all information for a given care flow
---

> We suggest reading the page on our [domain model](/awell-orchestration/docs/getting-started/domain-model) first to get an understanding of the care flow model.

## Request

### Query

```graphql
query GetPathway($pathway_id: String!) {
  pathway(id: $pathway_id) {
    pathway {
      id
      title
      pathway_definition_id
      patient_id
      patient {
        id
      }
      latestActivities {
        id
        stream_id
        date
        action
        status
        resolution
        reference_id
        container_name
        isUserActivity
        public
        object {
          id
        }
        indirect_object {
          id
        }
        track {
          id
        }
        label {
          id
        }
        sub_activities {
          id
        }
        context {
          instance_id
        }
      }
      version # version number
      release_id # unique id representing the version
      status
      status_explanation
      start_date
      complete_date # if care flow is completed
      stop_date # if care flow is stopped
      start_context { # how and by whom the care flow was started
        source {
          type # api / enrollment / trigger / webhook / migration / test / unknown
        }
        started_by {
          kind # human / system / integration
        }
        started_at # ISO8601 format
      }
    }
  }
}
```

### Variables

```json
{
  "pathway_id": "{{PATHWAY_ID}}"
}
```
